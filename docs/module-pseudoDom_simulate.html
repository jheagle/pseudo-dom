Methods

(inner) click(element, initopt) → {boolean}

Click an element the way a user does: pointerdown and mousedown, then the focus moves to the nearest element which can have it (or is taken away from the one which had it) unless mousedown was cancelled, then pointerup, mouseup and finally click. Every event is trusted and has the options the browser gives it. A disabled element gets nothing.
Parameters:

element * The element to click
init Object <optional>
