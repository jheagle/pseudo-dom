Class: HTMLCollectionService

HTMLCollectionService(owner, predicateopt, deepopt)

Simulate the behaviour of the HTMLCollection Class when there is no DOM available: a live view of some of a node's element descendants, recomputed each time it is used rather than kept in sync as they change.

Constructor

new HTMLCollectionService(owner, predicateopt, deepopt)

owner NodeService The node this is a live view of a part of

 Only elements which pass this are included (every element by default)
deep boolean <optional>
 false Include every matching descendant (true, like getElementsByTagName), not just the direct element children (false, like Element.children)
