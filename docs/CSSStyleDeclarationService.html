Class: CSSStyleDeclarationService

CSSStyleDeclarationService(cssTextopt)

Simulate the behaviour of the CSSStyleDeclaration Class when there is no DOM available: an ordered map of CSS property/value pairs, parsed from and serialized back to a cssText string. Values are stored and returned as given, with no unit conversion, shorthand expansion or validation - this is a data structure, not a real CSS engine. Named property access (declaration.backgroundColor, camelCase) is added on top of this by createStyleDeclaration, which wraps an instance of this class in a Proxy.
