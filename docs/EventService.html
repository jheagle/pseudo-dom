bubbles boolean A Boolean indicating whether the event bubbles up through the Dom or not.
cancelable boolean A Boolean indicating whether the event is cancelable.
composed boolean A Boolean value indicating whether the event can bubble across the boundary between the shadow Dom and the regular Dom.
currentTarget function | PseudoEventTarget A reference to the currently registered target for the event. This is the object to which the event is currently slated to be sent; it's possible this has been changed along the way through re-targeting.
defaultPrevented boolean Indicates whether event.preventDefault() has been called on the event.
immediatePropagationStopped boolean Flag that no further propagation should occur, including on current target.
propagationStopped boolean Flag that no further propagation should occur.
eventPhase int Indicates which phase of the event flow is being processed. Uses EventService constants.
target EventTarget | PseudoEventTarget A reference to the target to which the event was originally dispatched.
timeStamp int The time at which the event was created (in milliseconds). By specification, this value is time since epoch, but in reality browsers' definitions vary; in addition, work is underway to change this to be a DomHighResTimeStamp instead.
type string The name of the event (case-insensitive).
isTrusted boolean Indicates whether the event was initiated by the browser (after a user click for instance) or by a script (using an event creation method, like event.initEvent)
