    Interface PseudoCSSStyleDeclaration

    Substitute for the DOM CSSStyleDeclaration Class. Real instances (from createStyleDeclaration) also accept arbitrary camelCase CSS property names (declaration.backgroundColor), which cannot be expressed in an interface.
